🚀 QUICK START

1️⃣  Create .env file with your configuration

    PORT=3000
    DATABASE_URL=postgresql://user:pass@localhost:5432/dbname
    JWT_SECRET=your-secret-key
    JWT_EXPIRE=7d
    CLOUDINARY_CLOUD_NAME=your_cloud_name
    CLOUDINARY_API_KEY=your_api_key
    CLOUDINARY_API_SECRET=your_api_secret

2️⃣  Setup database

    pnpm db:push

3️⃣  Start development server

    pnpm dev

4️⃣  Open in browser

    http://localhost:3000/health

💡 ARCHITECTURE HIGHLIGHTS
═══════════════════════════════════════════════════════════════════════════════════

Request Flow:
   Client → Middleware → Routes → Controllers → Services → Database

Separation of Concerns:
   Routes     - URL mapping
   Controllers - Request handling
   Services   - Business logic
   Database   - Data persistence

This architecture makes the code:
   ✅ Scalable      - Easy to add new features
   ✅ Maintainable  - Clear file organization
   ✅ Testable      - Each layer can be tested independently
   ✅ Reusable      - Services can be called from multiple controllers
